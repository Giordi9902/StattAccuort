# Sicurezza

## Segnalare una vulnerabilità

Non aprire una issue pubblica. Usa la funzione
[**Report a vulnerability**](https://github.com/Giordi9902/StattAccuort/security/advisories/new)
di GitHub oppure scrivi a [contact@stattaccuort.it](mailto:contact@stattaccuort.it).

Indica, se puoi:

- il componente coinvolto (API, web app, app iOS, infrastruttura);
- i passi per riprodurre il problema;
- l’impatto che ti aspetti.

Rispondiamo appena possibile e ti teniamo aggiornato fino alla correzione.

## Cosa ci interessa di più

- Modi per aggirare il limite di frequenza delle segnalazioni o per inondare la mappa di
  segnalazioni false.
- Accesso alla dashboard admin senza `ADMIN_TOKEN`.
- Qualunque modo di risalire a un dispositivo o a una persona partendo dalle segnalazioni: l’API
  salva solo un’impronta HMAC troncata, mai IP o User-Agent.
